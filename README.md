# 🔍 Intelligent Job Search Portal

A full-stack web application built with Flask that revolutionizes job matching through AI-powered classification and semantic search capabilities.

## 🚀 Key Features

**For Job Seekers:**
- **Semantic Search Engine**: Advanced keyword matching with stemming normalization
- **Real-time Results**: Instant job matching with relevance scoring
- **Dynamic Preview**: Interactive job listing exploration
- **Search Analytics**: Display matching advertisement counts

**For Employers:**
- **AI-Powered Classification**: Automated job category prediction using ML
- **Intelligent Form Processing**: Smart job posting with category suggestions
- **Manual Override Options**: Flexible category customization
- **Instant Indexing**: New listings become searchable immediately

## 🛠️ Tech Stack & Architecture

- **Backend Framework**: Flask (Python)
- **Machine Learning**: Scikit-learn ensemble models
- **NLP Pipeline**: NLTK for text preprocessing & tokenization
- **Word Embeddings**: Gensim FastText for semantic understanding
- **Data Processing**: Pandas & NumPy for feature engineering
- **Frontend**: Jinja2 templating with responsive HTML/CSS
- **Storage**: File-based persistence with structured data management

## 💡 Intelligent Systems

- **ML Classification Engine**: Predicts job categories from descriptions
- **Natural Language Processing**: Text normalization and feature extraction
- **Search Optimization**: Stemming algorithms for keyword expansion
- **Real-time Data Pipeline**: Seamless integration between posting and search

## 🎯 Business Impact

- **Enhanced Search Relevance**: AI-driven matching improves candidate experience
- **Reduced Manual Effort**: Automated categorization streamlines operations
- **Scalable Architecture**: Modular design supports future enhancements
- **Data-Driven Insights**: ML models continuously improve classification accuracy
